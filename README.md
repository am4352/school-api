# 🏫 School API

A RESTful API to manage schools and fetch nearby schools based on user's coordinates. Built with **Node.js**, **Express**, **Prisma ORM**, and **MySQL**.

---

## 📦 Tech Stack

- **Backend**: Node.js, Express
- **ORM**: Prisma
- **Database**: MySQL
- **HTTP Tool**: Postman (for testing)

---

## 🚀 Features

- Add a new school
- Get list of schools sorted by distance from a user’s location
- Distance calculated using **Haversine formula**
- Error handling and validation
